# 🐟 涂鸦画鱼应用 2.0

这是涂鸦画鱼应用的2.0版本，基于原始版本进行了重大改进和功能增强。

## 项目介绍

一个允许用户绘制自己的鱼并让它们在虚拟鱼缸中游泳的交互式应用程序。

## 快速开始

### 安装依赖
```bash
npm install
```

### 启动开发服务器
```bash
npm run dev
```

### 构建生产版本
```bash
npm run build
```

## 2.0版本改进计划

- 全新的用户界面
- 增强的绘制工具
- 更多的鱼行为选项
- 社区鱼缸功能
- 鱼的定制化选项
- 性能优化

## 技术栈

- React
- TypeScript
- Vite
- Canvas API
